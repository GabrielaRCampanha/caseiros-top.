# Caseiros Top – Sistema de Gestão e Organização da Pastelaria

## Sobre o projeto

O **Caseiros Top** é um projeto acadêmico que propõe o desenvolvimento de um sistema de gestão para uma pastelaria familiar.

A proposta surgiu da necessidade de melhorar a organização dos pedidos, do estoque de ingredientes e das movimentações financeiras, facilitando as atividades do dia a dia e reduzindo a dependência de anotações em papel e controles manuais.

## Problema identificado

Atualmente, a pastelaria utiliza cadernos, anotações, WhatsApp e controles manuais para organizar seus pedidos, acompanhar os ingredientes e registrar entradas e saídas financeiras.

Esse processo pode dificultar a localização de pedidos, o acompanhamento do estoque e a conferência do caixa, principalmente nos períodos de maior movimento.

## Objetivo do projeto

Desenvolver uma solução simples e organizada que ajude a centralizar as principais informações da pastelaria, facilitando o acompanhamento das atividades e contribuindo para uma gestão mais eficiente.

## Funcionalidades previstas

- Cadastro e consulta de produtos.
- Registro e consulta de pedidos.
- Atualização do status dos pedidos:
  - Recebido;
  - Em preparação;
  - Pronto;
  - Entregue.
- Registro manual de entradas e saídas de ingredientes do estoque.
- Registro de entradas e saídas financeiras.
- Consulta de movimentações financeiras e saldo por período.

## Tecnologias planejadas

As tecnologias previstas para o desenvolvimento do projeto são:

- **Python:** linguagem de programação.
- **Flask:** desenvolvimento da aplicação web.
- **HTML e Bootstrap:** estrutura e interface do sistema.
- **Flask-SQLAlchemy:** comunicação com o banco de dados.
- **PostgreSQL:** armazenamento das informações.
- **Pytest:** testes da aplicação.
- **Visual Studio Code:** ambiente de desenvolvimento.

## Público-alvo

O sistema é pensado inicialmente para atender à rotina de uma pequena pastelaria familiar, podendo futuramente ser adaptado para outros pequenos estabelecimentos que necessitem organizar pedidos, estoque e movimentações financeiras.
